# dev_gcli

Google Cloud / CLI & Productivity Projects Repository.

## Projects

### 1. [sheets-inapp-splitview](./sheets-inapp-splitview/)
- **구글 시트 인앱 스플릿뷰 (Google Sheets In-App SplitView)**
- Chrome 브라우저 및 구글 시트 PWA 앱 창 내부에서 동일한 시트 파일을 2분할(좌/우 비교 및 실시간 동기화)하여 볼 수 있도록 해주는 크롬 확장 프로그램입니다.
- 단축키: `Alt + S` 또는 `Cmd/Ctrl + Shift + S`
- 드래그 가능한 중앙 리사이저 바(Splitter) 지원

### 2. [gdocs-splitview](./gdocs-splitview/)
- **구글 문서 분할뷰 (Google Docs SplitView)**
- 단일 탭 내에서 여러 Google Docs, Sheets, Slides 문서를 나란히 열고 관리할 수 있는 Chrome 확장 프로그램입니다.

### 3. [dwg-lite-studio](./dwg-lite-studio/)
- **DWG Lite Studio for Mac**
- 무거운 AutoCAD 전체 설치 없이 맥에서 `.dwg` / `.dxf` 도면의 글자·선·블록을 간편하게 수정하고 원하는 인쇄 범위(Plot Window)를 지정해 벡터 PDF로 출력할 수 있는 경량 로컬 CAD 웹 & CLI 프로그램입니다.

### 4. [hwp-to-pdf-mcp](./hwp-to-pdf-mcp/)
- **HWP/HWPX to PDF 변환 MCP 서버**
- macOS 한컴오피스 한글(`Hancom Office HWP.app`)의 내부 헤드리스 엔진(`libSimpleEngineLib.dylib`)을 REA로 연동하여, GUI 없이 `.hwp`, `.hwpx` 문서를 고품질 `.pdf`로 변환하는 Model Context Protocol (MCP) 서버입니다.

### 5. [Latcraft](./Latcraft/)
- **Latcraft (macOS Workspace & Window Manager)**
- macOS 가상 데스크톱(Space) 전환, 창 관리 및 핫키 기반 생산성 향상을 위한 Swift 기반 네이티브 데스크톱 애플리케이션입니다.
